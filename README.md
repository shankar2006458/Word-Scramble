# 🎮 Word Scramble Game

A modern, mobile-first word puzzle game where players unscramble letters to form correct words. Built with a sleek UI, smooth animations, and engaging gameplay mechanics.

---

## 🚀 Features

* 🎯 **Multiple Difficulty Levels**

  * Easy, Medium, Hard

* 📚 **Word Categories**

  * General, Fruits, Technology, Vegetables, Animals, Mix mode

* ⏱️ **Timer-Based Gameplay**

  * Race against the clock to score higher

* 💡 **Smart Hint System**

  * Start with 1 hint
  * Earn extra hints every 4 correct words

* 🔥 **Score & Streak System**

  * Points based on word length + remaining time
  * Track streaks and best streak

* 🎉 **Visual Feedback**

  * Confetti on correct answers
  * Shake animation on wrong answers
  * Glow effects for success

* ⏸️ **Pause & Resume**

  * Smooth pause overlay
  * Resume with 3…2…1 countdown

* 🔊 **Sound Effects**

  * Click, correct, and wrong feedback sounds

* 🏆 **High Score Tracking**

  * Stored using localStorage

* 📱 **Mobile-First Design**

  * Fully responsive and touch-friendly

---

## 🧠 How to Play

1. Choose **difficulty** and **category**
2. Click **Play**
3. Tap letters to form the correct word
4. Use:

   * 💡 Hint (reveals correct letter)
   * ⏭ Skip (move to next word with penalty)
5. Score as high as possible before time runs out!
